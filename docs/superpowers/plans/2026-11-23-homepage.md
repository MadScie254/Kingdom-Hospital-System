# Public homepage and portal entry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public, fast, accessible hospital homepage at `/`, two sign in doors, a logo that opens the dashboard inside the portal, and a way back to the website.

**Architecture:** The page is a prerendered server component in this Next.js app with a small set of client components (header, phone menu, scroll reveal, cataract slider, portal link). Facts live in one module, `lib/site.ts`, that the page, the structured data and the tests all read. Motion is CSS first, with IntersectionObserver only to add a class once.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind 4 plus a scoped `app/home.css`, `@fontsource-variable/atkinson-hyperlegible-next`, `tsx --test`, Playwright for browser checks, OpenNext on Cloudflare Workers.

**Spec:** `docs/superpowers/specs/2026-11-23-homepage-design.md`

## Global Constraints

- Phone shown as `0742 007 277`, linked as `tel:+254742007277`. Email `kingdomfaithbasedhospital@gmail.com`. Open 24 hours, every day. Insurance copy says SHA members are welcome.
- Palette: ink navy `#0e2a47`, azure `#2a6fae`, lens blue `#8ec1ee`, sky wash `#eaf3fb`, chart white `#fbfdff`, signal red `#b8362b` (only the 24 hour marker and the emergency note).
- One typeface, Atkinson Hyperlegible Next, weights 400, 600, 800. Body 18 px on 1.6. Lines under 70 characters.
- Motion: easing `cubic-bezier(.2,.7,.2,1)`, durations 160, 420 and 900 ms. Everything off under `prefers-reduced-motion`, and content must be visible without JavaScript.
- No emojis and no dashes in visible text. Sentence case. No postal code, WhatsApp number, prices, outcomes, testimonials or staff names.
- CSP: same origin only. Photos and font are self hosted. The map is a link.
- Bundle under 3 MiB compressed (`wrangler deploy --dry-run`). Page weight under 600 KB. Each photo under 120 KB.
- The root layout says `noindex`. The homepage overrides it. Nothing else changes.

## Review Focus

1. A signed in person opens `/`: they see the homepage with an Open portal button, never a redirect loop.
2. The admin door with a staff account: signed out again and told to use Hospital staff, never left half signed in.
3. `/api/session` with an expired, forged or garbage cookie: `{ signedIn: false }`, no error.
4. JavaScript fails or is slow: every section is readable (reveal classes only ever hide after JS has started).
5. A 360 px phone: no sideways scroll, the menu opens, traps focus, closes on Escape and on a link tap.
6. The cataract slider by keyboard: arrows, Home and End work and the value is announced.

## File Structure

- `lib/site.ts` (new): hospital facts, `PORTAL_HOME`, `loginMode`, `allowedForMode`, `jsonLd`. No imports.
- `lib/site-content.ts` (new): the copy as data (services, cataract facts, about, SHA, visit).
- `app/api/session/route.ts` (new): `GET` returns `{ signedIn, role }` from the cookie only.
- `app/page.tsx`, `app/home.css`, `app/sitemap.ts`, `app/robots.ts` (new or replaced): the page and search files.
- `components/site/*.tsx` (new): `site-header.tsx`, `portal-link.tsx`, `reveal.tsx`, `cataract-slider.tsx`, `eye-chart.tsx`, `services.tsx`.
- `public/images/home/*.webp`, `public/og.jpg` (new): the photos.
- `app/login/page.tsx`, `components/shell.tsx`, `app/(app)/dashboard/page.tsx`, `app/signup`, `app/forgot`, `app/reset` (modify): doors, logo links, back link.
